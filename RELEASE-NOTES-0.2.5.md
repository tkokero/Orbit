Orbit 0.2.5 brings a new Controller Mode, a connected Desktop design, and more control over menus, privacy, and everyday library use.

## What's new

- New Controller Mode with customizable bindings, artwork-focused game pages, and optional interface sounds.
- Refreshed Desktop UI with clearer text, consistent buttons, improved spacing, and better artwork sizing.
- Resize popups and choose between shared sizing or separate saved sizes for each menu.
- Read Steam announcements inside Orbit.
- Improved downloads, easier access to collections, and clearer game menus.
- Expanded Discord Rich Presence privacy controls for shared games and activity.

## Fixes and improvements

- More reliable settings and theme preservation across restarts and updates.
- Smoother navigation, improved game launch handling, and more consistent popup sizing, artwork, and alignment.
- Background checkups stay out of the way while you play.

## Downloads

- **Orbit-Setup.exe** — recommended Windows x64 installer, with automatic updates.
- **Orbit-Windows.zip** — portable build; extract the entire folder before opening Orbit.exe.
- **Orbit-Source.zip** — matching source, tests, and build documentation.
- **latest.yml** and **Orbit-Setup.exe.blockmap** — files used by the updater.
