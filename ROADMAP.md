# Orbit Roadmap

This roadmap outlines the milestones leading to Orbit 1.0. Orbit focuses on delivering a fast, responsive, and unified game launcher for Windows.

---

## Current Release: 0.2.8 (Everyday Desktop)
- Custom Desktop layouts (Gallery, Workspace, Shelf) with live customization preview and reorderable sections.
- Collection management with drag-and-drop game assignment and per-collection saved views.
- Activity correction tools: edit session times, merge sessions, and 7-day correction history recovery.
- Steam and Discord friend linking with primary profile selection.
- Experimental Graphics presets and SteamVR overlay dashboard.

---

## Upcoming Milestones

### 0.3.0 - Game Clipping & Replay Buffer
- **Replay Buffer:** Capture and save the last moments of gameplay with a configurable hotkey and buffer length.
- **Recording Controls:** Explicit capture source selection, recording status indicators, and emergency stop.
- **Local Clip Library:** In-app clip playback, simple trimming, and export controls.
- **Privacy & Performance:** Purely local capture; low-overhead background encoding using hardware acceleration where available.

### 0.4.0 - Clip Workspace & Editing
- Timeline scrubbing, multi-cut trimming, and thumbnail previews.
- Clip tagging, title metadata, and game filtering.
- Background export queue with customizable resolution and framerate presets.

### 0.5.0 - Profile Portability & Backup
- Guided profile backup and migration between PCs (themes, collections, layout preferences, and local history).
- Conflict resolution when restoring onto an existing installation.
- Safe path remapping for moved libraries.

### 0.6.0 - VR Dashboard Polish
- Inward-facing wrist display, gaze visibility, and SteamVR dashboard refinement.
- Responsive desktop window capture panels in VR space.
- Hardware playtest validation and performance tuning.

### 0.7.0 - Expanded Integrations & Importers
- Robust library rescans, error recovery for unmounted drives, and missing game path detection.
- Honest, clear reporting of online vs. offline status.

### 0.8.0 - Public Beta & Polish
- Extensive performance audits across CPU, RAM, and startup pacing.
- Accessibility review: keyboard shortcuts, high-contrast themes, screen-reader compatibility, and UI scaling.

### 0.9.0 - Release Candidates
- End-to-end upgrade verification, installer reliability, and data safety checks.
- Code signing preparation and release documentation finalization.

### 1.0.0 - General Availability
- Stable, polished Windows release with dependable game launching, library organization, customization, and local clipping.
