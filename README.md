# Orbit

Orbit brings your game libraries into one place. Find installed games, organize your collection, and launch the copy you want without searching through separate apps.

## Get started

1. Download **Orbit-Windows.zip** from [Releases](https://github.com/tkokero/Orbit/releases/tag/v1.0.0-pre.1).
2. Extract the entire archive and run **Orbit.exe** inside the extracted folder. Keep the folder's files together.
3. Follow the setup guide to discover your libraries and choose your preferences. You can skip optional connections and return to setup from **Settings → General**.
4. Choose a game and select **Play**, or open **Details** for more options.

## Your library

- Browse games and tools separately, search by title, and filter your collection.
- Combine duplicate entries while keeping their original sources visible. Installed copies take priority.
- Favorite games, hide entries, or add an executable manually.
- Use the recently played section to continue where you left off.
- Right-click a game for quick actions and library management.

## Game details

View available playtime, achievements, artwork, installation information, and launch options in one place. When a platform does not provide playtime, use Orbit's local tracking while Orbit is running. Information depends on what each library makes available; private or missing data remains unavailable.

## Install and manage

Open installation actions from game details or choose a standalone installer file. Account-based downloads may open the original store or launcher. Supported downloads show progress and time estimates when sufficient data is available.

Check published system requirements against your computer where supported. Some components require manual comparison. Browse available discounts and confirm pricing on the store before purchasing.

## Make it yours

Choose a built-in theme or create, import, and export your own palette. Settings include startup behavior, automatic library discovery, motion preferences, and display options. Reopen the setup guide whenever you need it.

## Friends

Connect supported accounts to view available friends, activity, and recent games. Privacy settings and platform support determine what appears. Status controls use the platform's official interface where available.
