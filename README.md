## Welcome to Orbit.

## Synced up game library
- Automatically discovers supported installed games and local library records, with Steam, Epic Games, and Others filters.
- Combines duplicate titles and favors the installed copy. Games and Tools stay separate.
- Supports standalone launchers, Minecraft, and mod tools including r2modman and CurseForge.
- Cached covers, recent-game banner, search, sorting, favorites, and right-click actions.
- Available platform playtime and achievements, plus local playtime tracking when platform hours are unavailable.
- Steam installation/download progress and launcher handoff where detailed progress is unavailable.

## Simple UI
- Dark, rounded interface with brief animations and reduced-motion support.
- 14 built-in palettes, a custom theme editor, and JSON theme import/export.
- Windows startup options, start minimized, minimize on play, remembered views, and automatic game discovery.
- Game-specific launch commands where supported.
- Bounded card rendering, cached artwork, file watchers, and work that pauses when its view is inactive.

## View your friends in one app
- Steam friends, shared presence, and Steam profile avatars through the official Web API.
- Recent-game cards with icons, titles, total hours, and hours played over the past two weeks when Steam shares them.
- Private data stays unavailable; recent games are separate from current activity.
- Images load on demand; recent-game details are cached for five minutes.
- Optional encrypted API key storage on Windows.
- Status controls open the official Steam, Epic Games, or Discord interface. Epic and Discord provide client controls only, not live friend feeds.

## Lightweight and Open Source
- Orbit uses close to 0 resources on your computer.
- Completely open for you to customize and tinker to your liking

## Download and run
**Orbit-1.0-Windows-qol.zip**: extract and run **Orbit-win32-x64/Orbit.exe**. Keep the full folder together. The Windows build is unsigned.

**Orbit-1.0-source-qol.zip**: complete MIT-licensed application source, tests, and documentation. Use this attached archive for the app source; GitHub's automatic source downloads reflect the repository tag.

**Orbit-demo-qol.zip**: extract and open **index.html** for the separate browser preview. **Orbit-demo-qol.gif** is an animated walkthrough. Both use familiar game names, sample friends/statistics, and original placeholder artwork; neither uses your personal library.

**README-current.md**, **FRIENDS.md**, **THEMES.md**, and **VALIDATION-current.md**: general usage, social capabilities, customization, and validation details.
