# Changelog

All notable changes to Orbit are documented in this file. Releases are available on [GitHub Releases](https://github.com/tkokero/Orbit/releases).

## [0.2.8] - 2026-11

### Added
- **Desktop Customization:** Gallery, Workspace, and Shelf layouts with live customization preview, section reordering, saved menu presets, and transparent top bar.
- **Library & Collections:** Drag games directly into collections, remember layout preferences per collection, and remove library entries with instant Undo and Restore.
- **Activity Tracking:** Edit session start and end times, merge overlapping sessions with gap exclusion, and 7-day correction history recovery.
- **Friends & Presence:** Choose primary Steam or Discord profiles for linked friends with refined profile controls.
- **UI Navigation:** Glide transitions, searchable dropdowns, and enhanced Settings navigation across narrow and wide displays.
- **Experimental Features:** Graphics config discovery and presets (NVIDIA, AMD Software handoff), VR dashboard trigger fixes, and expanded documentation.

---

## [0.2.7] - 2026-11

### Added
- **Global Search:** Search games, collections, settings, and quick actions together (Ctrl+K); configurable keyboard shortcuts.
- **Launch Options:** Add custom launch arguments and alternate executables per game without overwriting default launch targets.
- **Activity & Streaks:** Per-game session tracking, launch streaks, and improved Activity filters.
- **Experimental VR:** Optional SteamVR overlay dashboard with wrist controls, performance graphs, and desktop window capture panels.
- **UI Refinements:** Redesigned Windows title bar, surface rounding, and new secret startup scenes.

---

## [0.2.6] - 2026-10

### Added
- **Library Layouts:** Switch between cover cards, landscape banners, or compact lists with adjustable card sizing and spacing.
- **Batch Organization:** Multi-game selection with Ctrl/Shift, pinned sidebar collections, and bulk Undo.
- **Friends:** Refreshed Friends view with Steam and Discord presence and profile linking.
- **News Reader:** In-app game news and announcements with inline images and active links.
- **Custom App Icons:** Match the Windows application icon to your selected theme.

---

## [0.2.5] - 2026-10

### Added
- **Controller Mode:** Fullscreen gamepad-driven interface with customizable button bindings, console-style game pages, and optional navigation sounds.
- **Desktop UI Refresh:** Improved contrast, consistent button geometry, and resizable modal frames with per-menu saved bounds.
- **Steam & Downloads:** Download queue tracking, folder space management, and local Steam debugging connection.
- **Privacy:** Granular Discord Rich Presence controls for hiding game titles or elapsed play time.
