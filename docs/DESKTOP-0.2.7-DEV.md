# Desktop 0.2.7 development

The current private candidate is **0.2.7-dev.27**. It is not a published release. Published 0.2.6 assets and its updater feed are untouched.

## Implemented

- Unified search, customizable keyboard shortcuts, named launch targets and launch recovery.
- Saved popup sizes/positions, context-menu keyboard access, and parent-menu scroll/focus restoration.
- Grouped Settings, direct search focus and Back to results.
- Local game session counts and streaks in details and Activity.
- Updated Void and a separate Afterglow: Encore. Original Afterglow remains available.
- Launcher-linked running-game detection, including Arknights: Endfield.

## Experimental

Orbit VR offers a SteamVR dashboard, window/display panels, Watch/Toolbar wrist layouts, compositor readings, media tools and reversible origin offsets. See [VR scope](VR-EXPERIMENTAL.md). Hardware, Virtual Desktop, headset input, real frame pacing and multiple-panel cost remain playtest work.
