# Orbit guides

Choose what you want to do. These steps describe 0.2.8; older builds can have different controls. Screenshots use sample libraries/profiles, not account data.

Start with Quick start and **Take a tour** inside Orbit. Reopen Quick start from Settings → About. **Ctrl+K** searches games, collections, settings and actions.

## Help and development

Report a problem from Settings → About with the build number, steps and visible error. Leave API keys, tokens and private files out of reports. [Privacy](../PRIVACY.md) explains local data and connections.
