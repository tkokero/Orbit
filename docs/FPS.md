# FPS estimates

Open **Estimate FPS** in game details. Orbit uses the current PC's detected CPU, GPU, and RAM. It does not launch a benchmark or change game settings.

1. Open a game's Details and choose **Estimate FPS** where available.
2. Check the detected hardware and the stated reference/settings.
3. Read the estimate as a range for that scenario, then measure actual gameplay if you need a benchmark.

Example: an estimated range does not promise the same FPS in every map, mod setup or headset. It is separate from the VR overlay's runtime readings and does not optimize the game for you.

**These are approximate ranges, not measured FPS or a performance guarantee.** Missing hardware or unsupported game information can prevent an estimate.

Some profiles use publisher targets for Cyberpunk 2077, Ghost of Tsushima Director's Cut, and Assassin's Creed Mirage. Other games use broader workload assumptions with greater uncertainty. The interface identifies the reference where available.

Patches, mods, laptop power limits, thermals, ray tracing, upscaling, frame generation, and scene complexity can change actual performance. VR estimates use a Desktop approximation and do not predict headset performance.

Hardware calculations stay local. A store lookup uses the requested game's store ID; Orbit does not continuously benchmark your PC.

See [the model and source references](reference/FPS-MODEL.md) for formulas, assumptions, and publisher links.
