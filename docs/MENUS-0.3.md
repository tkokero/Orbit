# Simpler menus — 0.3.0 development builds

Current paths for **0.3.0-dev.7**. The 0.2.8 guides describe the older button positions.

| I want to… | Where it lives |
| --- | --- |
| Change a game's launch options | Game details → Game options → Launch options |
| Open its folder, locate its executable, install or uninstall | Game options → Files & installation |
| Change or repair artwork | Game options → Artwork |
| Change graphics, read requirements or estimate FPS | Game options → Performance |
| Move, remove or wishlist a game | Game options → Collections |
| View game news or session recaps | Game details → Activity |
| Get launch help, save backups or check game detection | Game options → Troubleshooting |
| Save notes, tags or collections | Edit the fields; Save appears when something changes |
| Import/export a library or restore removed entries | Settings → Manage → Library |
| Restore a backup or review library health | Settings → Manage → Backup and cleanup |
| Open reports or export the library table | Settings → Manage → Reports and exports |
| Import or export a theme | Settings → Appearance → Theme import/export buttons |
| Refresh VR status or pin VR to the sidebar | VR → Check again / Pin to sidebar |
| Show a saved clip's file | Open the clip player → Show file |
| Mute the clip-save sound | Clips → Capture settings → Play a sound when a clip is saved |

Menu actions support arrow keys and Escape. Destructive actions keep their existing review or confirmation. Closing an informational popup uses its header close control; confirmation and capture controls remain reachable.

Saving stays explicit. Orbit does not autosave notes, tags or collection edits just because their Save buttons are hidden before a change. The former More game actions catch-all is removed; each group now stays small and beside its related content.
