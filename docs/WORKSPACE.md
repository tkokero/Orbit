# Library workspace

Open **Settings → Appearance → Layout** and choose the **Library & details** preview. The original **Artwork & shelves** interface stays available.

- Select a game to see its card beside the grid. Use **Play**, or double-click the game, to launch.
- **Game settings** beside Play opens its options directly. Click the card artwork for full details.
- Use Overview, Activity and Files in the card. Saved clips and Game news open their related content.
- Use the view controls beside the grid for covers, banners or a list. **Customize** changes card size and spacing.
- Ctrl-click selects several games; Shift-click selects a range. Bulk changes offer Undo.
- Choose library and sidebar styles independently under **Customize layout**. Move the game card left or right, or hide it.
- Both interfaces use the same Settings popup and share games, recordings, themes and accounts. Controller mode keeps its existing layout.

See [Desktop layouts](DESKTOP-LAYOUTS.md) and [Clipping](CLIPPING.md).
