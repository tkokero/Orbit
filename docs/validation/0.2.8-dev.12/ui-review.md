# Orbit UI redline

Product: a personal Windows game launcher for desktop players.
Character: rounded, readable, expressive.
World: game artwork and a quiet instrument panel, within the user's chosen theme.
Moments: real game art, and clearly aligned Current/New graphics values.
Signature: a small selected-state accent, with original Orbit and provider symbols.

Audit: 56 existing wide and Controller captures reviewed, plus narrow/scaled captures in final validation.
- Config picker: oversized filled result buttons, repeated explanations, full paths and a three-action stack.
- Graphics: repeated titles, disclaimers and helper text crowd the table.
- Controls: inconsistent pill shapes, weights and disclosure decoration across dialogs.
- Settings: several nested borders and utility actions compete with the setting labels.
- Context menus and quick actions: retain semantics and keyboard behavior; align hit areas.
- Library, Radar, Friends, Downloads, Activity, Steam and Tools: retain established layouts; use shared control cleanup and check geometry, states and theme contrast.
- Controller Home/Library, startup artwork and native notifications: keep intentional content and specialized shapes; check shared regressions without replacing those layouts.
- VR runtime surfaces: review source and existing limits; a headset playtest is not performed by hidden desktop checks.

Use existing palette and fonts; no generated assets. Apply spacing, color, icons, copy, type, layout, details, visuals and motion in that order.
