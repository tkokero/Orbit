# Orbit 0.3.0

- Save game replays with a shortcut, or record full sessions locally.
- Choose capture quality up to 1440p, optional microphone audio, and specific apps or output devices. Save audio presets and per-game recording choices.
- Browse, search and play clips inside Orbit, with a sound when a clip is saved.
- Try the optional Library workspace: a game grid with a larger details panel and direct Game settings.
- Mix library and sidebar styles, customize layouts, and let Recents fit the available space automatically.
- Refreshed Quick Start, cleaner menus, and fixes for game tracking, library removal, clip playback, navigation, background previews and missing audio devices.

Download **Orbit-Setup.exe** to install or update. For portable use, extract the entire **Orbit-Windows.zip** before opening Orbit. Windows x64 · Unsigned.

VR overlay and Graphics settings remain experimental. Capture compatibility and performance vary by game, device and Windows configuration. Recordings stay local; cloud sharing, automatic highlights, trimming and separate audio-track editing are not included.
