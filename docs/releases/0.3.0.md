# Orbit 0.3.0

## Clipping

- Save recent gameplay with a shortcut, or record full sessions with bookmarks for moments you want to revisit. Recordings stay local as MP4 files.
- Capture a detected game, or choose a window or display from visual previews. Optional startup arming waits for a detected game; it never switches to desktop capture automatically.
- Adjust replay length, recording quality up to 1440p and frame rate. Customize the Save and Stop shortcuts, change them during recording, and choose whether a sound confirms each saved clip.
- Record game audio, PC audio, selected apps or output devices, with an optional microphone and separate volume controls. Save audio presets; returning devices reconnect to their remembered selections.
- Set recording modes for individual games, session and library size limits, and low-space protection. Saved recordings are never deleted automatically, and interrupted recordings remain labelled in the library.
- Find recordings with search, game filters and date groups. Watch them in Orbit with a larger player, Previous/Next, playback speed, fullscreen and bookmark navigation; returning to the gallery keeps your place.

- Delete a clip from its player or right-click menu, with confirmation and Windows Recycle Bin recovery. Clip details stay in a hidden folder beside your videos.

## Desktop additions

- An optional Library & details interface puts the game grid beside a larger selected-game panel, with direct Game settings and Overview, Activity and Files tabs.
- Mix either library interface with either sidebar. Move or hide the details panel, choose visible page shortcuts and save the combination.
- Recents automatically adjusts the number of games to the available width.
- A reworked Quick Start guides appearance, startup, library and preference choices, then leads into the tour or clipping setup.

Clip playback, audio recovery and Workspace navigation handle interruptions more reliably, inactive previews release their media, and interrupted automatic-update checks retry sooner.

Download **Orbit-Setup.exe** to install or update. For portable use, extract the entire **Orbit-Windows.zip** before opening Orbit. Windows x64 · Unsigned.

Capture compatibility and performance vary by game, device and Windows configuration. Interrupted recordings may be incomplete or unplayable.

Right-click menus now offer relevant actions for clips, downloads, friends, news, collections and saved games.
