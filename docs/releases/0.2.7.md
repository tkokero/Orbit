# Orbit 0.2.7

- Search games, collections, settings, and actions together. Customize your keyboard shortcuts.
- Add named launch options while keeping each game's default setup.
- View per-game session counts and play streaks, with easier Activity filtering.
- Cleaner Settings and more consistent, resizable popups, with better scrolling and keyboard focus.
- New secret startup choices and improvements to Void.
- UI and reliability fixes, including long labels, expand arrows, older game history, and clearer launch recovery.

**Experimental VR:** Open an optional SteamVR dashboard, wrist displays, and window/display panels, with media and performance tools. Find it under **More → VR**. SteamVR is required; headset tuning and performance testing are ongoing.

Download **Orbit-Setup.exe** to install or update. For portable use, extract the complete **Orbit-Windows.zip** first. Windows builds are unsigned.
