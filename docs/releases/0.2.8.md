# Orbit 0.2.8

- Customize Desktop with Gallery, Workspace and Shelf layouts, a live preview, section ordering, saved layouts and a transparent top bar.
- Drag games into collections, remember each collection’s view, and remove library entries with Undo and Restore.
- Edit, merge or remove recorded sessions with reviewed changes and seven-day recovery. Platform playtime stays unchanged.
- Choose a main Steam or Discord profile for linked friends, with clearer profile controls.
- Glide transitions, easier Settings navigation, searchable dropdowns and cleaner menus across narrow and wide layouts.
- Find early features in More → Experiments. Experimental Graphics settings finds recognized configs and offers reviewed edits, backups and Restore.
- Improved NVIDIA discovery, matching and Stop/Retry controls. AMD per-game settings open in AMD Software.
- Fix VR dashboard trigger-release clicks, reduce repeated Appearance work, and expand the practical guides.

Graphics settings and the VR overlay remain experimental. Config support varies by game; VRChat exposes particle limits rather than general graphics. Live NVIDIA Apply and the latest physical-headset input changes have not been confirmed on hardware.

Download **Orbit-Setup.exe** to install or update. For portable use, extract all of **Orbit-Windows.zip** before opening Orbit. Windows x64 · Unsigned · Pre-release. Clipping remains a development prototype, planned for 0.3.0.
