# Orbit 0.2.8 draft

- Edit recognized VideoConfig graphics files across games, including Apex, with named controls. Unsupported files are clearly view only.
- Find local game configs automatically and compare named graphics settings, with backups and Restore for local edits.
- See game artwork in config search, switch between Played and All games, and find more configs through corrected folder matching.
- Remove games from Orbit without uninstalling them, with Undo and Restore.
- Faster repeat NVIDIA checks, corrected Overwatch matching, and Stop/Retry controls. NVIDIA Apply still needs a live playtest; AMD profiles open in AMD Software.

- Glide transitions connect startup and menus, with steady popup frames and responsive controls.
- Easier menu navigation: return to your last Settings section, type to find dropdown options, and move through right-click submenus with fewer clicks. Duplicate actions are reduced, with Settings in More when its sidebar route is unavailable.
- Customize Desktop menus with Gallery, Workspace and Shelf layouts. Move navigation, adjust content width, make the top bar transparent, hide or reorder sections, and save named layouts.
- Choose a main profile for linked Steam and Discord friends. Discord is the default; both identities and their individual presence stay available.
- Calmer Settings and Friends controls, readable expanded profiles, and preserved profile expansion and keyboard focus during refresh.
- Correct recorded session times, merge split sessions, or remove unwanted recordings, with a preview and Undo.
- Recover the latest session correction for seven days, including after restarting Orbit.
- Drag games into manual collections and keep separate layouts and card density for each collection.
- Select multiple sessions and use Orbit menus for actions that fit your selection.
- Keep play counts and streaks accurate after corrections while retaining older recorded totals.
- Clearer collection forms, reachable popup actions, wrapped Storage cards, and consistent header order after resizing.
- Less repeated UI work while Appearance is closed, fewer redundant saves, and clearer session-history and backup labels.
- Small Activity improvements for selection, keyboard access, focus, light themes and narrow windows.

History corrections affect only Orbit recordings and leave platform playtime unchanged. Game config edits happen only after Apply. This is an unpublished development build.
