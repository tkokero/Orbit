# Controller Mode

Open **More → Controller mode** for the fullscreen interface. Choose **Desktop** in its menu to return. Startup scenes can be skipped.

## Controls

| Action | Default control |
| --- | --- |
| Move | D-pad or left stick |
| Select | A / Cross / Nintendo A |
| Back | B / Circle / Nintendo B |
| Open navigation | Tap Menu / Options / + |
| Game actions | Hold Menu / Options / + |
| Change tab | Shoulder buttons |
| Scroll | Right stick |
| Quick wheel | Hold View / Share |

Change bindings, deadzone, repeat timing, or Confirm/Back in **Controller Settings → Controller**. Desktop has the same controls under **Settings → General → Controller navigation**. Conflicting bindings are rejected.

## Finding and playing games

Home shows recent games and discovery feeds. Library has covers, search, and filters. Select a game for its page, then choose **Play**. The menu also opens Downloads, Favorites, shelves, Shuffle, and Settings.

Orbit stays visible while a game starts, switches when its detected window is ready, and returns after the session ends. If switching is blocked, choose **Switch to game**. **Keep browsing** leaves the launch running. Configure the executable in Game detection if Orbit cannot recognize it.

## Menus and appearance

In Settings, move up/down through categories, right into their controls, and left or Back to return. Confirm opens text fields and dropdowns; left/right adjusts sliders. The on-screen keyboard supports English letters, numbers, and common symbols.

Themes, startup scenes, reduced motion, and saved popup sizes work in both modes. **Controller Settings → Sound** has separate volume, mute, and previews. Desktop startup sound is separate. Moving the mouse restores pointer control.

## Limits

- Support depends on Chromium's standard controller mapping, drivers, and Steam Input. Individual USB/Bluetooth setups can behave differently.
- Windows file pickers, sign-in windows, other launchers, and games use their own controls.
- Guest mode hides personal information on Orbit's pages; it is not account security.
- Store controller labels do not guarantee every game menu supports a controller.

For diagnostics and tests, see [Contributing](CONTRIBUTING.md) and [Validation](VALIDATION.md). Clipping and synthetic-input tools remain developer-only.
